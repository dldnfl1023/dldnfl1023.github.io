Shorts Factory 개인정보처리방침

시행일: 2026년 11월 7일

1. 개요

Shorts Factory(이하 "앱")는 운영자가 본인의 YouTube 채널(「지구는 둥글둥글」, 「지식이 몽실몽실」)에 직접 제작한 영상을 업로드하기 위해 사용하는 개인용 도구입니다. 앱은 YouTube API 서비스를 사용하며, 앱을 사용하는 것은 YouTube 서비스 약관에 동의하는 것을 뜻합니다. Google의 정보 처리 방식은 Google 개인정보처리방침을 참고하세요.

2. 접근하는 정보

앱은 Google OAuth 2.0으로 운영자가 직접 허용한 다음 권한만 사용합니다.

  • youtube.upload — 운영자 채널에 동영상과 썸네일을 업로드
  • youtube.readonly — 업로드 대상 채널의 이름·ID 확인, 업로드한 동영상의 처리 상태 확인

앱은 시청자, 구독자, 댓글 작성자 등 다른 사람의 개인정보를 수집하지 않습니다.

3. 정보의 이용·저장

  • OAuth 인증 토큰은 운영자 본인 컴퓨터의 로컬 파일에만 저장되며, 외부 서버로 전송하지 않습니다.
  • YouTube API로 받은 정보는 업로드 기능 수행에만 사용하며, 광고·분석·판매 목적으로 사용하지 않습니다.
  • Google 사용자 데이터는 제3자에게 판매하거나 공유하지 않습니다.

앱의 Google API 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

4. 쿠키

앱은 웹 서비스가 아니므로 쿠키나 유사 기술로 기기 정보를 저장·수집하지 않습니다.

5. 보관 기간과 삭제

인증 토큰은 운영자가 삭제하거나 접근 권한을 철회할 때까지 로컬에 보관됩니다. 언제든지 Google 보안 설정의 서드파티 앱 권한 페이지에서 앱의 접근 권한을 철회할 수 있으며, 철회하면 앱은 더 이상 YouTube 데이터에 접근할 수 없습니다. 로컬 토큰 파일도 즉시 삭제합니다.
